# Sunday Picks Web

Aplicación web construida con React + TypeScript + Vite.

## Requerimientos

- Node.js 20 o superior (recomendado LTS).
- npm 10 o superior.
- API backend disponible (por defecto: `http://localhost:8080`).

## Variables de entorno

Crear un archivo `.env` en la raíz del proyecto con:

```env
VITE_API_URL=http://localhost:8080
```

## Instalación

1. Instalar dependencias:

```bash
npm install
```

## Ejecución

1. Levantar en modo desarrollo:

```bash
npm run dev
```

2. Abrir en navegador:

```text
http://localhost:5173
```

## Build y preview

1. Generar build de producción:

```bash
npm run build
```

2. Ejecutar preview local del build:

```bash
npm run preview
```

## Lint

Ejecutar validación de código:

```bash
npm run lint
```
